# Система учёта инвентаря компьютерных классов

Консольное приложение на Python для учёта компьютерного оборудования в учебных кабинетах.

## Цель проекта

Разработать работающую программу, которая позволяет:
- просматривать список оборудования;
- добавлять, изменять и удалять записи;
- искать оборудование;
- сохранять данные в файл JSON.

Проект выполняется командой из 3 человек с использованием Git, тестирования и ролями (Product Owner, Lead Developer, QA/DevOps).

## Текущий статус (Спринт 1)

Реализовано:
- Главное меню программы
- Просмотр списка оборудования
- Демонстрационные данные (6 записей)
- Базовая структура проекта

В следующих спринтах будут добавлены:
- Добавление, редактирование и удаление записей
- Поиск
- Сохранение в JSON
- Автоматические тесты
- Документация пользователя
