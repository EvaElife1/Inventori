# Система учёта инвентаря компьютерных классов

Консольное приложение на Python для учёта компьютерного оборудования в учебных кабинетах.

## Цель проекта

Разработать работающую программу, которая позволяет:
- просматривать список оборудования;
- добавлять, изменять и удалять записи;
- искать оборудование по номеру и кабинету;
- сохранять данные в файл JSON.

## Текущий статус (Спринт 4)

Реализовано:
- Полный базовый CRUD (создание, чтение, изменение, удаление)
- Поиск по инвентарному номеру и по кабинету
- Валидация данных и запрет дубликатов инвентарного номера
- Подтверждение при удалении
- Надёжное хранение данных в JSON
- Автоматическая загрузка данных при запуске
- Корректная обработка отсутствующего и повреждённого файла
- Модуль `storage.py` для работы с файлом
- Автоматические тесты (inventory + storage)
- Dockerfile (опционально)

## Формат хранения данных

Данные хранятся в файле `data/inventory.json` в формате JSON-массива.

Пример одной записи:
```json
{
  "inventory_number": "INV-001",
  "type": "ПК",
  "name": "Системный блок Dell OptiPlex 7090",
  "cabinet": "301",
  "status": "исправно",
  "date_received": "2024-09-12",
  "responsible": "Иванов А.С."
}
