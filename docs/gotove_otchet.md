---

## 1. Цель и проблема

В колледже терялась информация об оборудовании.
Нужна была простая система учёта: просмотр, добавление, поиск, изменение, удаление и сохранение данных.

**Результат:** работающее консольное приложение на Python + JSON + тесты + документация.
