# Система учёта инвентаря компьютерных классов

Консольное приложение на Python для учёта компьютерного оборудования в учебных кабинетах.

## Возможности

- Просмотр всего оборудования
- Добавление новых записей с валидацией
- Поиск по инвентарному номеру и по кабинету
- Изменение состояния, кабинета и ответственного
- Удаление записей с подтверждением
- Автоматическое сохранение в JSON
- Безопасная обработка отсутствующего и повреждённого файла данных

## Требования

- Python 3.11 или новее
- Windows / macOS / Linux

### 3. Как пользоваться программой

После запуска на экране появится главное текстовое меню. Введите цифру нужного пункта и нажмите Enter:

* `1` — Показать всё оборудование  
  Выводит полный список техники из базы с указанием инвентарного номера, типа, названия, кабинета и текущего состояния. Если база пуста, система сообщит об этом.
* `2` — Добавить новую запись  
  Пошагово запрашивает данные о технике.
* `3` — Найти оборудование  
  Позволяет быстро найти карточку устройства по его уникальному инвентарному номеру (или отфильтровать по кабинету, если функция добавлена). Если номер не найден, выведется соответствующее предупреждение.
* `4` — Изменить запись  
  Запрашивает инвентарный номер существующего устройства и позволяет обновить его кабинет (при переносе техники) или состояние (например, если компьютер сломался).
* `5` — Удалить запись  
  Удаляет карточку оборудования по инвентарному номеру. Для защиты от случайного удаления программа попросит подтверждение: введите `Y` (да) или `N` (отмена).
* `6` - Фильтр по кабинету/состоянию
* `0` — Выход  
  Корректно завершает работу приложения.

### 4. Хранение данных и поведение при ошибках

* Автосохранение: Все изменения записываются в файл data/inventory.json сразу после выполнения операций. При следующем запуске данные подгружаются автоматически.
* Первый запуск / удаление файла: Если папки data/ или файла inventory.json нет, программа создаст их автоматически при старте.
* Повреждение файла данных: Если data/inventory.json был отредактирован вручную с ошибкой синтаксиса, при запуске программа не «упадёт», а выведет предупреждение о повреждении файла, чтобы не перезаписать ваши данные вслепую.

### 5. Известные ограничения системы
[13.11.2026 12:28] ~•Min•~: 1. Только консольный интерфейс (CLI): Управление происходит исключительно с клавиатуры в терминале; графический интерфейс и управление мышью не поддерживаются.
2. Локальное хранение без облачной синхронизации: Вся база находится в одном файле data/inventory.json. При физическом удалении этого файла без резервной копии данные восстанавливаются только с нуля.
3. Однопользовательский режим: Программа не рассчитана на одновременный запуск и редактирование одного файла inventory.json несколькими людьми по сети.
4. Отсутствие истории изменений (логов аудита): Система хранит только актуальное состояние карточки (кто и когда перенёс компьютер из кабинета в кабинет, в базе не фиксируется).
5. Ограниченный поиск: Поиск ориентирован на точное совпадение инвентарного номера (частичный или нечёткий поиск с опечатками не поддерживается).
