## Отчёт LD

### Реализовано

- `find_by_number(data, inv)` — поиск по номеру (регистронезависимый, `.strip()`).
- `find_by_room(data, room)` — список записей кабинета.
- `search_by_number`, `search_by_room` — сценарии меню.
- `edit_item(data)` — изменение `room` и `status`.
- `delete_item(data)` — удаление с подтверждением Y/N.
- `save_data` / `load_data` — сохранение после каждой операции.

### Технические решения

- Регистр не важен: `.lower()` с обеих сторон.
- Все вводимые строки проходят `.strip()`.
- Единое сообщение «Не найдено» для поиска, изменения, удаления.
- Удаление только при `answer == "y"`; пустой ввод = отказ.
- `status` проверяется по справочнику `{"исправно", "требует ремонта", "списано"}`.
- Пустой ввод нигде не роняет программу.
- `save_data` вызывается после каждой операции.
