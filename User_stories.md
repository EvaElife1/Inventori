# User Stories
## Система учёта инвентаря компьютерных классов

---

### US-01. Просмотр списка оборудования
**Как** лаборант,  
**я хочу** видеть полный список всего оборудования,  
**чтобы** понимать, какое оборудование есть в наличии и в каком оно состоянии.

**Критерии приёмки:**
- При выборе пункта меню «Показать всё оборудование» отображается список всех записей.
- У каждой записи видны: инвентарный номер, тип, наименование, кабинет, состояние, дата поступления, ответственный.
- Если записей нет — выводится сообщение «Список оборудования пуст».
- Программа не завершается с ошибкой.

**Статус:** Выполнено

---

### US-02. Добавление нового оборудования
**Как** администратор,  
**я хочу** добавлять новую запись об оборудовании,  
**чтобы** учитывать поступившее оборудование.

**Критерии приёмки:**
- Можно ввести все поля карточки.
- Инвентарный номер можно оставить пустым — система генерирует его автоматически.
- Обязательные поля: тип, наименование, кабинет, состояние.
- При пустых обязательных полях запись не создаётся, выводится список ошибок.
- Нельзя добавить запись с уже существующим инвентарным номером.
- После успешного добавления запись сразу появляется в общем списке и сохраняется в файл.

**Статус:** Выполнено

---

### US-03. Поиск по инвентарному номеру
**Как** лаборант,  
**я хочу** находить оборудование по инвентарному номеру,  
**чтобы** быстро узнать, в каком кабинете оно находится и в каком состоянии.

**Критерии приёмки:**
- Поиск по существующему номеру показывает полную карточку записи.
- Поиск по несуществующему номеру выводит сообщение «Запись не найдена».
- Пустой ввод не приводит к аварийному завершению программы.

**Статус:** Выполнено

---

### US-04. Поиск по кабинету
**Как** лаборант,  
**я хочу** видеть всё оборудование, находящееся в конкретном кабинете,  
**чтобы** проводить инвентаризацию в аудитории.

**Критерии приёмки:**
- При указании существующего кабинета выводятся все записи этого кабинета.
- При отсутствии оборудования в кабинете выводится понятное сообщение.
- Можно найти несколько записей сразу.

**Статус:** Выполнено

---

### US-05. Изменение записи
**Как** администратор,  
**я хочу** изменять состояние, кабинет и ответственного лица,  
**чтобы** поддерживать данные в актуальном состоянии.

**Критерии приёмки:**
- Можно изменить состояние, кабинет и/или ответственного.
- Поля, которые пользователь оставил пустыми, не изменяются.
- При указании несуществующего номера выводится сообщение «Запись не найдена».
- Изменения сразу сохраняются в файл.

**Статус:** Выполнено

---

### US-06. Удаление записи
**Как** администратор,  
**я хочу** удалять записи об оборудовании,  
**чтобы** убирать списанное или ошибочно добавленное оборудование.

**Критерии приёмки:**
- Перед удалением программа показывает карточку записи.
- Удаление требует явного подтверждения (да/нет).
- При отмене удаления запись остаётся без изменений.
- При указании несуществующего номера выводится сообщение «Запись не найдена».
- После подтверждения запись удаляется и больше не отображается в списке.

**Статус:** Выполнено

---

### US-07. Сохранение данных между запусками
**Как** пользователь,  
**я хочу**, чтобы все изменения сохранялись в файл,  
**чтобы** данные не терялись после закрытия программы.

**Критерии приёмки:**
- После перезапуска программы все ранее добавленные и изменённые записи остаются на месте.
- При отсутствии файла программа запускается с пустым списком и не падает.
- При повреждённом JSON-файле программа выводит сообщение и продолжает работу с пустым списком (без незаметной потери данных).

**Статус:** Выполнено
