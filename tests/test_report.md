## 1. Цель и объём работ

Цель спринта 5 — «Проверка на прочность»: расширить набор автотестов минимум до 10, выполнить регрессионную проверку, оформить отчёт, проверить запуск по README.

Выполненный объём:

| Модуль              | Что проверено                                                                 |
|---------------------|-------------------------------------------------------------------------------|
| inventory.py        | add_item, валидация, дубликаты номеров, search_by_number, search_by_cabinet, update_item, delete_item, generate_inventory_number |
| storage.py          | отсутствующий файл, повреждённый JSON, неверная структура, save → load        |
| CLI (main.py)       | ручная проверка всех пунктов меню 1–7, обработка ошибочного ввода, отмена удаления |
| Окружение           | запуск по README, прогон pytest                                               |

Итого: **16 автотестов** (требование спринта — минимум 10), покрытие всех операций CRUD и файлового хранилища + ручной чек-лист CLI.

6. Известные ограничения
Только консольный интерфейс.
Нет разграничения прав пользователей.
Нет истории изменений записей.
Docker — дополнительный артефакт, не обязателен.
При сильно повреждённом JSON данные не восстанавливаются (файл заменяется пустым списком после предупреждения).
Автотесты не запускают main() целиком — покрытие CLI выполняется ручным чек-листом.
